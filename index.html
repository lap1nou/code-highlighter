Code highlighter for Word

Paste code, pick a language and theme, then copy it into Word with its colors. Everything runs from this folder, and its security policy blocks all network access, so your code never leaves your machine.

Preview on a page

Your highlighted code appears here, as it will look in Word.

This theme uses light text, which will be hard to read on a white page. Turn on “Keep theme background” or choose a light theme.

In Word, paste with “Keep Source Formatting” (plain Ctrl+V usually does). Selecting part of the preview and pressing Ctrl+C keeps the colors too.
